# Innovate-Well-Consultancy

## Overview
The **Disease Prediction System** is a GUI-based application built using **Tkinter** in Python. It allows users to predict the likelihood of a disease based on input symptoms. The system is powered by a **RandomForestClassifier** machine learning model to provide predictions.

## Features
- User-friendly **Tkinter GUI** for disease prediction
- Uses **RandomForestClassifier** for accurate predictions
- Accepts **three input symptoms** for diagnosis
- Predicts possible disease based on trained model
- Displays the prediction result in an easy-to-read format

## Technologies Used
- **Python**
- **Tkinter** (for GUI)
- **Scikit-learn** (Machine Learning)
- **Pandas** (for data handling)
- **NumPy**

## Installation
Follow these steps to set up and run the project on your local machine:

### Prerequisites
Ensure you have Python installed. If not, download and install it from [Python.org](https://www.python.org/downloads/).

### Clone the Repository
```bash
git clone https://github.com/yourusername/disease-prediction-system.git
cd disease-prediction-system
```

### Install Dependencies
Run the following command to install the required dependencies:
```bash
pip install -r requirements.txt
```

### Run the Application
Execute the Python script to launch the application:
```bash
python app.py
```

## Usage
1. Open the application by running `python app.py`.
2. Enter three symptoms in the provided input fields.
3. Click on the **Predict** button.
4. The predicted disease will be displayed in the application window.

## Dataset
The model is trained on a medical dataset containing symptoms and their corresponding diseases. The dataset is preprocessed and used to train a **RandomForestClassifier**.
